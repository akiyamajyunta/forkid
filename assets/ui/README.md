# ゲーム画面 UI 素材

## 背景（星蓮船風）

| ファイル | 用途 |
|----------|------|
| `bg_pattern.jpg` | 全体の和柄背景 |
| `bg_overlay.png` | 背景の上に重ねる枠・グラデーション風オーバーレイ |

## 任意パーツ

このフォルダに画像を置くと、ゲーム画面で自動的に使われます（無い場合は従来のベクター描画）。

## 推奨ファイル名

| ファイル | 用途 |
|----------|------|
| `main_frame.png` | 左メインエリア全体の外枠（1024×600 基準でスケール） |
| `question_panel.png` | 問題文エリアの背景（伸縮可・9パッチなら後で対応） |
| `option_bar.png` | 選択肢バー（未選択） |
| `option_bar_selected.png` | 選択肢バー（カーソルあり） |
| `status_panel.png` | 右ステータス欄の背景 |

任意:

- `gauge_timer.png` / `gauge_bonus.png` … ゲージの枠や塗り
- `font/` … TTF/OTF（丸ゴ・UD教科書体など）

## 形式

- PNG 推奨（透過あり可）
- 基準解像度: レイアウトは **1024×600** を基準にスケールします
- 送付時に「どの画像がどのファイルか」と、9パッチの境界（あれば）をチャットで書いてください
