# UI・画面レイアウト・操作仕様 (README_UI.md)

## 担当範囲
画面遷移（タイトル・モード選択・ゲーム画面）、キーボード操作、レイアウト・ビジュアルデザイン。

## 1. 画面構成
1. **タイトル画面**: ゲーム開始、操作説明への遷移。
2. **モード選択画面**: 「イージー」「ノーマル」「ハード」の選択。
3. **ゲーム画面**:
   - 画面構成は**『東方星蓮船』風**のレイアウトを採用。
   - **左側**: ゲームメインエリア（問題文、選択肢一覧）。
   - **右側**: ステータスバー（残りライフ、タイマーゲージ、ボーナスゲージ、ボム所有数、正解数[?/10]）。

## 2. デザインテイスト
- **「AI生成っぽさ」を排除**:
  - 過度にフラットすぎず、かといって過剰なグラデーションや幾何学模様を避ける。
  - レトロゲーム感のあるドット絵調、または温かみのある手描き風のアナログ質感を取り入れたUIパーツを採用。
  - 子供に見やすい大きな文字・可読性の高いフォント（UDデジタル教科書体や丸ゴシック系など）を使用。

## 3. 操作仕様（キーボード・コントローラー対応）
PCキーボード/ゲームパッドの対応マッピング：

| 操作内容 | キーボード入力 | ゲームパッド（対応表記） |
| :--- | :--- | :--- |
| **選択移動** | 十字キー (`↑` `↓` `←` `→`) | 十字キー |
| **決定** | `X` キー | Xボタン |
| **ボム発動** | `Y` キー | Yボタン |
| **メニュー（一時停止）** | `Shift` キー | Menu / Selectボタン |
