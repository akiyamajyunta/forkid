# システムロジック・ゲームルール仕様 (README_SYSTEM.md)

## 担当範囲
ゲームの難易度設定、ライフ管理、タイマー、ボーナスゲージ、ボム機能、勝敗判定の設計と実装。

## ゲームルール仕様

### 1. 難易度と問題パラメータ
| 難易度 | 選択肢 | タイムリミット | 備考 |
| :--- | :--- | :--- | :--- |
| **イージー** | 3択 | 無制限 | 低学年・未就学児向け |
| **ノーマル** | 4択 | 1問あたり3分 | 標準 |
| **ハード** | 6択 | 1問あたり1分 | チャレンジ向け |

### 2. ゲーム進行ルール
- **クリア条件**: 10問正解
- **ゲームオーバー条件**: ライフが0になる、またはいずれかの問題でタイムアップ（ノーマル・ハード）
- **ライフ**: ミス（不正解）するごとに1減少。

### 3. 特殊ルール（ボム・ボーナス）
- **ボム機能**:
  - 発動すると、画面上の間違った選択肢を**半分削る**（3択なら1つ除外、4択なら2つ除外、6択なら3つ除外）。
- **ボーナスゲージ & ボム増加**:
  - 各問題の回答速度に応じて「ボーナスゲージ」が溜まる。
  - ゲージが満タンになるとボムの発動可能回数が+1される。
